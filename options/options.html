🌐 服务端点

本扩展中需要联网的功能（DNS 查询、WHOIS、IP 归属地、证书透明度、子域名枚举、汇率、泄露查询等）都通过下列「服务端点」访问外部服务。你可以把任意一类指向自己的服务器，或更换为其他服务商 —— 无需修改任何代码。

如何接入自建服务：在对应类别的「服务商」中选择「自定义服务（自建 / 自托管）」，然后填写你的服务地址（支持 {name}、{type} 等占位符），你的服务只需返回该类别的归一化 JSON 结构即可。

自建服务接入指南 （含各类别的参数说明、返回结构，以及可直接部署的示例适配器）

ToolCube

纯本地运行，保护隐私

一款功能强大的浏览器扩展，整合了覆盖文本处理、编码解码、数据格式、设计视觉、网络工具、元素检查、金融换算、密码安全、API 调试、跨时区协作等多个领域的实用与极客工具。

功能特点

  • ✅ 实用与极客工具，覆盖文本、编码、设计、网络、密码、API 调试
  • ✅ 纯本地运行，所有数据处理均在浏览器内完成，保护您的隐私
  • ✅ 浮动侧边栏设计，随时随地调用，支持拖拽和缩放
  • ✅ 支持快捷键、收藏夹、分类折叠、历史记录
  • ✅ 深色/浅色主题自动切换（跟随系统）
  • ✅ 视频倍速控制器与视频解锁/进度伪装
  • ✅ 图形化元素检查器，轻松查看和修改 DOM
  • ✅ 银狐木马下载拦截、追踪器屏蔽、HTTPS 强制升级
  • ✅ 多浏览器兼容：Chrome / Edge / Firefox / Kiwi 等
