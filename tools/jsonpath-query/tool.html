📖 JSONPath 语法参考
语法说明示例
$根对象$
.name点号访问子节点$.store
['name']括号访问（含特殊字符）$['store']
[n]数组下标（支持负数）$[0] / $[-1]
[*]通配符（所有元素）$.store.book[*]
[start:end:step]数组切片$[:5] / $[::2]
..name递归搜索$..author
[?(expr)]过滤表达式$[?(@.price<10)]
@当前节点（过滤中）[?(@.price>10)]
&& / ||逻辑运算[?(@.a>1 && @.b<5)]
